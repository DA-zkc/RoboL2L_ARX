## SDK 完成不等于实测到位

新增 `adapters/arx_native.py` 在已有控制器上读取安装中 SDK 的规划器和参考轨迹状态，不创建控制器、不改变原生运动参数。常驻 owner 仅暴露固定 `plan_duration/reference_status/joint_path` 查询。

原始轨迹在 SDK 参考结束后返回，回执包括实测误差且 `physical_arrival_verified=false`。高层 move 仍依据调用方的公差返回成功或可恢复精度错误。夹爪 `target_reached=None`、`grasp_verified=false`；SDK 默认夹爪指令可能立即完成参考更新，不能把它当作手指已停止或已持物。Agent 应用实际反馈判断任务完成。

取消项目超时后，参考不结束、相机不出帧或活着的 owner 不回复时，可以持续等待；不再虚构时间到期等于电机故障。暂停仍是后续派发边界，不是当前 SDK 动作的急停。
